# CharacterCounter

Учебная C++20 программа для подсчёта количества вхождений каждого символа из заданного множества в тексте.

## Возможности

- ручной ввод исходных данных;
- загрузка исходных данных из файла;
- автоматический расчёт после ручного ввода или загрузки;
- немедленный вывод результата вместе с исходным текстом;
- сохранение исходных данных и результата в одном UTF-8 файле;
- повторная загрузка исходных данных из сохранённого файла;
- обработка существующего файла с выбором перезаписи или нового имени;
- обработка файлов, доступных только для чтения;
- поддержка русских и английских символов.

## Паттерны

В проекте используются:

- Strategy — алгоритм подсчёта задаётся через `ICharacterCountingStrategy`;
- Factory — `CountingStrategyFactory` создаёт конкретную стратегию подсчёта.

## Контейнер

Основной алгоритм использует:

`std::unordered_map<wchar_t, int>`

Ключ — символ множества, значение — количество его вхождений в тексте.

## Visual Studio

Проект рассчитан на C++20. Для Visual Studio рекомендуется включить стандарт C++20 и `/utf-8`. Программа самостоятельно переводит консоль Windows в Unicode-режим через `_setmode`.

## Формат файла

Сохранённый файл имеет вид:

```text
CHARACTER_COUNTER_DATA

TEXT
Привет, мир!

SYMBOLS
3
и
р
!

RESULT
и 1
р 2
! 1
```

При загрузке программа читает секции `TEXT` и `SYMBOLS`, после чего автоматически выполняет расчёт заново.
